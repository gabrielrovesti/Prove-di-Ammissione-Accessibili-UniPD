\section*{Formula della velocità media}

La velocità media di un corpo in moto uniforme è:

\begin{equation}
    v = \frac{\Delta s}{\Delta t}
\end{equation}

dove:

\begin{itemize}
    \item $v$ è la velocità media (m/s);
    \item $\Delta s$ è lo spazio percorso (m);
    \item $\Delta t$ è l'intervallo di tempo (s).
\end{itemize}

\section*{Media aritmetica con testo alternativo esplicito}

\begin{equation}[media aritmetica uguale sommatoria da i uguale 1 a n di x sub i, diviso n]
    \bar{x} = \frac{\displaystyle\sum_{i=1}^{n} x_i}{n}
\end{equation}

Proprietà principali:

\begin{itemize}
    \item È sensibile ai valori anomali (outlier);
    \item La somma degli scarti dalla media è sempre zero:
          $\displaystyle\sum_{i=1}^{n}(x_i - \bar{x}) = 0$;
    \item Minimizza la somma dei quadrati degli scarti.
\end{itemize}
